# StudySprint ⚡

A simple study planner built with HTML, CSS and JavaScript.

## Features
- Add study tasks with durations and priorities
- Mark tasks as complete
- Delete tasks
- Track task counts, planned minutes and completion progress
- Save tasks in the browser using localStorage
- Responsive layout for smaller screens

## Technology
- HTML for structure
- CSS for styling and responsive layout
- JavaScript for app behaviour
- Browser localStorage for saving tasks
- GitHub Pages for hosting

## What I learned
- How to organise a basic web app
- How to deploy a website using GitHub Pages
- How to test features and verify saved data

## Current limitations
- Tasks are saved in the current browser, not synchronised across devices
- There are no user accounts or cloud database
- This is a learning project, not a production-grade study platform
